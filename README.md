# 弦上知音 —— 古琴艺术智能学习与数字体验平台

> 移动端 App 原型（跨平台，基于 Flutter）· 单机离线可用

面向 **古琴零基础初学者 / 古琴文化爱好者 / 非遗文化体验用户**，围绕古琴数字化科普与基础学习，
交付一个可演示的八大核心功能原型。

---

## 一、八大核心功能与实现对照

| # | 功能 | 实现位置 | 说明 |
|---|------|----------|------|
| 1 | 古琴文化资料库 | `lib/features/culture/` | 历史 / 形制 / 琴派 / 工艺 / 琴道 分类浏览与全文检索 |
| 2 | 古琴三维模型展示 | `lib/features/model3d/` | 轻量化自绘 3D：透视投影 + 画家算法 + 简易光照，拖拽旋转 / 双指缩放 / 自动旋转 |
| 3 | 琴曲资料查阅 | `lib/features/pieces/` | 结构化元数据（朝代 / 传谱 / 宫调 / 难度 / 时长）+ 背景典故 + 收藏 |
| 4 | 减字谱学习 | `lib/features/notation/` | SVG 矢量谱面（四宫格拆解），符号点击即释义；另含「拼字练习」 |
| 5 | 指法动画教学 | `lib/features/fingering/` | 散音 / 泛音 / 按音与左右手指法动画演示，支持暂停、倍速、弦序切换 |
| 6 | 简易演奏辅助 | `lib/features/assist/` | 节奏跟弹 → 音高 / 节奏比对 → 判定与评分反馈 |
| 7 | 琴音可视化 | `lib/features/visualize/` | 时域波形 + 频域频谱（谐波能量），对比散 / 按 / 泛音音色 |
| 8 | 数字琴境体验 | `lib/features/realm/` | 晨曦 / 暮云 / 夜月三境虚拟场景 + 可触摸七弦（涟漪、弦振、诗意回响） |

配套页面：首页总览（`features/home/home_page.dart`）、习琴、体验、我的（学习进度 / 收藏 / 项目说明）。

## 二、技术栈

| 方向 | 方案 |
|------|------|
| 客户端框架 | Flutter · Dart · 跨平台 Android |
| 本地存储 | SQLite（`sqflite`）· 单机离线可用 |
| 减字谱渲染 | SVG 矢量方案（`flutter_svg`）· 可缩放可交互不模糊 |
| 指法动画 | 矢量动画方案 · 体积小播放流畅 |
| 音频处理 | 麦克风采集 · Librosa 特征提取 · 模型转换 TFLite 部署移动端 |
| 三维渲染 | GLB 轻量化模型 · `model_viewer_flutter` |

## 三、运行方式

环境要求：Flutter SDK ≥ 3.16（Dart ≥ 3.0），Android 模拟器或真机。

```bash
flutter pub get
flutter run
```

> 注意：本地存储使用 `sqflite`，请在 **Android / iOS 模拟器或真机** 上运行。
> 浏览器（Chrome）等平台不支持 sqflite，需先替换为 `sqflite_common_ffi` 或 Web 适配实现。

## 五、原型阶段的实现取舍（重要）

本项目定位为 **可演示的原型 Demo**，优先保障核心学习功能的完整闭环，对重资源能力做了轻量化处理：

| 能力 | 原型实现 | 正式版本方案 |
|------|----------|--------------|
| 三维展示 | 轻量自绘 3D（透视投影 + 画家算法 + 光照），零素材、离线可跑 | `model_viewer_flutter` 加载 GLB 轻量化模型 |
| 指法动画 | `CustomPainter` 逐帧自绘矢量动画（散 / 泛 / 按音，双手联动 + 侧视画中画） | 即本实现，无需外部动画资源 |
| 琴音可视化 | 本地谐波模型合成信号驱动波形 / 频谱 | 麦克风采集真实音频 + FFT 频谱分析 |
| 演奏辅助 | 触摸节拍 → 音高 / 节奏比对 → 判定评分 | 麦克风采集 → Librosa 特征提取 → TFLite 本地推理 |
| 音频播放 | 试听进度示意（不含真实音频资源） | 内置琴曲音频资源与真实播放器 |

替换点均已隔离在各自 feature 目录内，接口清晰，可平滑升级，不影响其余模块。

## 六、数据说明

内置种子数据（`lib/data/seed_data.dart`）包含：

- **琴曲 10 首**：广陵散、流水、梅花三弄、平沙落雁、阳关三叠、潇湘水云、酒狂、良宵引、醉渔唱晚、乌夜啼
- **文化资料 8 篇**：琴有三千年、七弦十三徽、琴式之美、琴派源流、斫琴工艺、琴者禁也、减字谱、三种音色
- **指法 15 项**：散音 / 泛音 / 按音 + 右手八法（擘托抹挑勾剔打摘）+ 左手指法（吟猱绰注）
- **常用减字 8 组**：按「左手指法 / 徽位 / 右手指法 / 弦序」四要素拆解

首次启动自动写入 SQLite，之后完全离线可用。
